## 커밋 규칙
`타입: 내용` 예: `feat: sorted()와 list.sort() 차이 예제 추가`

| 타입 | 용도 |
|------|------|
| `feat` | 새 예제 코드, 실습 추가 |
| `fix` | 기존 코드 오류 수정 |
| `docs` | README, 노트 수정 |
| `refactor` | 동작은 그대로, 코드 정리 |
